# Prueba de evaluacion UNICEN 2026

**Prueba técnica: Sistema académico**  
**Enunciado**  
La universidad  central(UNICEN) en su necesidad de actualizar sus tecnologias ha pedido desarrollar un nuevo sistema académico con backend, frontend y base de datos, en un tiempo máximo de **4 horas**. El objetivo es construir un proyecto funcional y bien estructurado con apoyo de herramientas de inteligencia artificial. No se requiere integrar agentes de IA en el producto.  
El sistema debe incluir los siguientes módulos:  

- **Cursos y materias:** catálogo de materias y oferta de cursos por gestion.  
- **Estudiantes e inscripciones:** registro de estudiantes e inscripción a cursos, con validación de cupo disponible e inscripción duplicada.  
- **Notas y calificaciones:** registro de notas por inscripción y consulta del historial académico.  
- **Autenticación y roles:** control de acceso passeto jwt por rol (administrador, docente y estudiante).  
**Stack sugerido:**  
- **Backend:** NestJS  
- **Frontend:** React  
- **Base de datos:** PostgreSQL  
- **Contenedores:** Docker Compose  
**Patrones de diseño**  
Se valorara el uso y conocimiento de arquitectura y patrones de diseño que considere adecuados y debera justificar en el README. Se valorará la coherencia entre la elección y el problema resuelto.  
`Ejemplos sugeridos` y valorados: Repository, Strategy, Factory, arquitectura por capas o hexagonal, Observer.  

**Entregables:**  

1. Repositorio Git con historial de commits.  
2. docker compose up que levanta base de datos, API y web.  
3. README con decisiones de arquitectura y justificación de los patrones elegidos.  
4. Diagrama de arquitectura.
